# 限制说明

当前测试版：`v0.9.9-beta`。

这个版本已经接近完整桌面端工作流，但它仍然依赖本地环境、第三方模型、TTS 服务和素材质量。下面这些限制需要在使用和发布时明确说明。

## 智能筛选不是词典数据库

应用现在使用统一智能筛选：

```text
素材 -> 本地高召回候选 -> AI 精筛推荐/候选 -> 用户选择学习点 -> 生成可用卡片 -> 用户勾选导出
```

系统会尽量把合法、有学习价值的词伙、语境生词、语法框架、听力难点和语气风险点放进学习点选择列表或诊断里，但它不是专业词典数据库，也不会保证每个可能的知识点都生成 Anki 卡片。v0.9.9-beta 起，普通视频制卡默认把这些学习点合并成一种“学习卡”，不再为同一个学习点拆出多张听力/表达/填空卡。

默认完整制卡只处理用户勾选的学习点。合法但优先级较低、重复度较高、目标过泛、无法在原句中清楚定位或需要人工确认的学习点会进入候选/诊断，而不是静默消失。

## 主流程只暴露沉浸复读

普通视频/字幕主流程已经收紧为一套 `沉浸复读 V11` 模板，两种模式：

- `完整复读`：默认完整背面。
- `快速复读`：正面同 V11，背面只保留原句、中文意思、视频、原声、慢读 TTS 和表达 TTS。

仓库中可能仍保留实验模板代码和测试，用于回归研究或后续分支开发；这些实验能力不应出现在普通用户主流程里。

## 发音和“原句听感”

V1 不做真实 ASR、forced alignment 或逐词级音频实听。除非未来明确接入音频验证，否则发音字段默认是：

```text
subtitle_inferred
```

意思是：根据字幕、上下文和常见口语规律推测。它不能被当作“剧中人物实际逐音素读法”的权威记录。

如果没有可靠发音内容，相关字段应留空或只进入内部诊断。公开卡面不应显示“未实听 / 已隐藏”这类占位话术，也不应把字幕推测包装成真实逐音素实听结果。

## YouTube 导入

YouTube URL 导入依赖 yt-dlp 和本机网络环境。失败原因可能包括：

- YouTube 临时限流或 HTTP 429；
- 字幕接口不可用；
- 区域限制、登录限制或代理问题；
- n challenge / EJS 规则变化；
- 本机缺少 Deno / Node.js，导致 yt-dlp 不能执行 challenge solver。

如果 URL 导入失败，建议先下载视频和 SRT，再走“本地视频 + SRT”。

## 没有字幕的素材

当前主流程更适合“视频 + 字幕”。如果本地视频没有 SRT，应用不能凭空得到稳定字幕。可行方案是：

- 先用在线 ASR 转成 SRT；
- 使用本地 ASR 模型转写；
- 后续接入应用内 ASR 工作流。

在没有字幕或转录文本的情况下，生成质量会明显下降。

## 模型和费用

模型 API 会接收字幕、候选学习点和生成请求。不同服务商的输出质量、速度、稳定性和费用差异很大。

当前设置页支持按服务商独立保存模型配置。Vertex 模式使用本机 `gcloud` OAuth，不需要在应用里保存 Vertex API Key。

长视频、全量候选召回、多语言发音说明和 TTS 都会增加时间与费用。生成慢通常不是单一问题，而是候选扩展、模型制卡、重试、TTS 和媒体裁切叠加造成的。

## TTS

TTS 可能产生费用。不同服务商的 voice、model、format、region 支持不完全一致。

导出时 AI TTS 默认降低到 65% 音量，用来平衡原视频原声和 AI 朗读的响度差异。这个音量处理只影响导出的 AI TTS，不改变原视频切片。

如果某个 TTS 服务返回空音频、格式异常或临时失败，应用会记录错误，避免把错误文件静默写进 APKG。

## 本地环境和一键修复

应用会检测 Python、Python worker 依赖、FFmpeg、Anki、AnkiConnect、yt-dlp 相关运行条件。

一键修复会尽量通过系统工具安装或修复可自动处理的项目，例如推荐 Python 3.12、FFmpeg、Anki、Python 依赖等。受 Windows 权限、winget 可用性、网络和安装包策略影响，部分项目仍可能需要用户手动确认或重启应用。

为什么不是“最新 Python”：当前推荐 Python 3.12，因为它更稳，依赖兼容风险低于追最新大版本。

## 媒体裁切精度

视频片段裁切基于字幕时间和词序估算。没有逐词级时间戳时，片段可能略早或略晚。后续如果接入 ASR word timestamps 或 forced alignment，对齐会更精确。

## 文档导入

当前发布版已经隐藏文档资料制卡入口。普通用户主流程只保留本地视频和视频链接；仓库里残留的文档相关代码只作为历史兼容或后续实验基础，不应作为当前公开能力宣传或验收。

## 版权和分享

生成的 `.apkg` 可能包含视频片段、字幕和 AI TTS 音频。默认用途是个人学习。公开分享 deck 前，请确认你有权分发这些素材。
