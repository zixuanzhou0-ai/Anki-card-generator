# Anki Card Generator v0.9.11-beta Release Notes

`v0.9.11-beta` 是 Windows 桌面端 beta 发布前的统一学习卡收口版本。本版不引入网页端 / Local Helper，继续聚焦本地 Windows 桌面端的视频到 Anki 制卡流程。

## 这版解决什么

- 用户侧只保留一种卡：`学习卡`。内部仍会记录词伙、单词用法、语法、听辨、语气等学习点标签，但这些只是筛选和解释维度，不再让用户理解成不同卡型。
- 学习点页的 `全选` 改为 `全选可制卡项`：推荐、候选、需复查但合法的学习点都会进入生成队列；重复折叠和不可制卡项不会进入队列。
- 默认选择仍然保守：系统先勾选高质量推荐项，用户需要更多内容时再手动点 `全选可制卡项`。
- 生成确认页明确区分学习点数量、生成卡片数量和可导出数量。
- 审核页的 `全选` 改为 `全选可导出`，只会选择已经通过媒体、TTS、字段和质量闸的卡。
- 如果选中的学习点没有全部生成，审核页会显示已选、成功生成、未生成和失败原因，并提供 `重试失败项`、`继续导出 N 张` 和 `返回学习点调整`。
- TTS 失败仍然阻止 APKG 导出，但会显示失败条目、失败阶段和重试按钮，不再只给一个含糊的“没有生成 APKG”。

## 卡片结构

每个选中的合法学习点默认最多生成一张 `学习卡`。

- 正面：英文原句、视频片段、原声、整句 TTS、表达 TTS。
- 反面：目标单词 / 词伙 / 表达、中文解释、语境义、用法提醒和必要的听辨或语气提醒。

## Windows 使用方式

1. 下载 Windows installer、MSI 或 portable zip。
2. 打开应用，进入 `设置 -> 模型 API` 配置模型。
3. 进入 `设置 -> 语音 TTS` 配置并测试 TTS。
4. 选择本地视频 + 字幕，或输入视频链接。
5. 点击 `抽取学习点`。
6. 使用默认推荐，或点击 `全选可制卡项`。
7. 生成 APKG，审核后点击 `全选可导出` 和导出按钮。
8. 如 Anki / AnkiConnect 可用，可执行导入核验。

## 已知限制

- 这是 Windows 桌面端 beta。macOS / Linux 桌面安装包暂未提供。
- 模型质量会受到字幕质量、视频领域、模型服务商和网络稳定性的影响。
- Vertex `gemini-3.5-flash` 更适合快速批量；如果需要更稳定的解释质量，建议使用更强模型。
- TTS、视频切片、媒体账本和 hash 仍是硬质量闸；这些失败时不会静默导出残缺 APKG。

## 安全与隐私

- API Key 和 OAuth 凭据只应保存在本机凭据或本地配置中，不应提交到 GitHub。
- Release 资产不包含测试视频、APKG、缓存、日志或本机密钥。
- 公开截图和文档应避免出现本机路径、私人字幕内容和 API Key。
